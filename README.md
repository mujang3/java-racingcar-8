# 🚗 자동차 경주 (java-racingcar)

## 🎯 구현 목표

사용자가 입력한 자동차 이름들과 시도 횟수를 바탕으로  
**무작위 값(0~9)** 중 **4 이상일 경우 전진하는 자동차 경주 게임**을 구현한다.  
모든 시도가 끝나면 **가장 멀리 전진한 자동차(복수 가능)**를 우승자로 출력한다.

---

## 🧩 기능 목록

1. **입력 처리**
    - 쉼표(,)로 구분된 자동차 이름 입력
    - 각 이름은 **1~5자** 이내여야 함
    - 시도 횟수는 **양의 정수**만 허용
    - 잘못된 입력 시 `IllegalArgumentException` 발생 후 프로그램 종료

2. **전진 로직**
    - 각 자동차는 0~9 사이의 랜덤값을 받음
    - 랜덤값이 4 이상이면 한 칸 전진

3. **경주 진행**
    - 매 시도마다 각 자동차의 이동 결과 출력
    - 라운드 종료 후 개행으로 구분하여 출력

4. **우승자 판정**
    - 가장 많이 전진한 자동차(들)를 찾음
    - 복수 우승자는 쉼표(,)로 구분하여 출력

5. **출력**
    - 예시와 동일한 형식으로 결과를 출력해야 함
    - 형식을 어기면 0점 처리

---

## ⚠️ 예외 처리

| 상황 | 동작 |
|------|------|
| 이름이 5자 초과 | `IllegalArgumentException` 발생 |
| 이름이 공백/빈 문자열 | `IllegalArgumentException` 발생 |
| 시도 횟수가 숫자가 아님 | `IllegalArgumentException` 발생 |
| 시도 횟수가 0 이하 | `IllegalArgumentException` 발생 |
